# KOAssistant Wiki

The reference for [KOAssistant](https://github.com/zeeyado/koassistant.koplugin#readme), the AI assistant plugin for KOReader. Every feature, option and menu path is described here; the README is the short overview and the place to start.

This wiki documents KOAssistant <!-- koa-version -->on the main branch<!-- /koa-version -->. The release you run may lack a few of the newest items; the [release notes](https://github.com/zeeyado/koassistant.koplugin/releases) say what each version added. The pages are kept in the repository's `wiki/` folder and published at every release.
